Learning goal

Explain how Git and GitHub work together to help people make and share changes safely.

01 / The big idea

Every project has a memory.

Software changes quickly. Version control gives a project a reliable memory: it records what changed, who changed it, and when. Git is the tool that creates that history. GitHub is the place where that history can be shared, discussed, and built on together.

G

Git

A distributed version control system that runs on your computer and tracks changes to files.

◉

GitHub

A cloud platform that hosts Git repositories and adds collaboration, automation, and community tools.

02 / Core vocabulary

Five building blocks.

Think of these as the nouns and verbs you will use in almost every GitHub conversation.

RepositoryA project folder plus its complete history.
CommitA saved snapshot with a message describing the change.
BranchAn independent line of work that can diverge and reunite.
RemoteA hosted copy of a repository, often on GitHub.
CloneA local copy of a remote repository.
