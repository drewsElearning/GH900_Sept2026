# GH-900 eLearning

> A practical learning repository for building confidence with GitHub fundamentals.

This repository supports learners preparing for **Exam GH-900: GitHub Foundations** and anyone who wants a structured introduction to GitHub. The curriculum follows the domains and skill areas published in the official [Microsoft Learn GH-900 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-900).

## Learning experience

The course moves from core concepts to hands-on collaboration, automation, project tracking, security, and community participation. Each module is intended to combine concise explanations with practical activities that can be completed in a GitHub repository.

### By the end of this course, learners will be able to:

- Explain the purpose of version control and the relationship between Git and GitHub.
- Navigate GitHub and describe the structure and key files in a repository.
- Make changes safely using branches, commits, and pull requests.
- Select the right collaboration tool for a task, including issues, pull requests, discussions, notifications, wikis, and Pages.
- Describe how GitHub Actions, Copilot, and Codespaces support modern development practices.
- Organize and track work with GitHub Projects.
- Apply foundational privacy, security, and account-access practices.
- Describe how open source and the GitHub community support shared learning and software development.

## Curriculum modules

The modules below mirror the official GH-900 domains. Percentages reflect the skill weighting listed in the Microsoft Learn study guide and are included to show relative emphasis, not to define a grading scheme.

| Module | Focus | Official exam domain |

| 01. Git and GitHub basics | Version control, Git concepts, GitHub navigation, and the GitHub flow | 25-30% |
| 02. GitHub repositories | Repository structure, README files, branches, commits, and repository management | 10-15% |
| 03. Collaboration with GitHub | Issues, pull requests, discussions, notifications, wikis, and GitHub Pages | 10-15% |
| 04. Modern development practices | GitHub Actions, GitHub Copilot, and GitHub Codespaces | 10-15% |
| 05. Project management with GitHub | GitHub Projects, views, layouts, and work organization | 5-10% |

| 07. The GitHub community | Open source, GitHub Sponsors, and responsible community participation | 5-10% |

## Module outcomes

### 01. Git and GitHub basics

- Describe the purpose and benefits of version control.
- Distinguish Git, GitHub, repositories, commits, branches, and remotes.
- Explain how GitHub supports collaboration around Git-based projects.

### 02. GitHub repositories

- Identify common repository files, including `README.md`.
- Explain how branches and commits help manage changes.
- Describe repository visibility, settings, and basic management tasks.

### 03. Collaboration with GitHub

- Use issues to discuss work, questions, and potential improvements.
- Describe how pull requests support review and controlled integration.
- Choose between issues, discussions, notifications, wikis, and Pages for common collaboration needs.

### 04. Modern development practices

- Describe the purpose and capabilities of GitHub Actions.
- Explain how GitHub Copilot can assist with development tasks.
- Describe how Codespaces provides a cloud-based development environment.

### 05. Project management with GitHub

- Describe GitHub Projects and its available layout options.
- Organize work items so that progress and priorities are visible.
- Connect project tracking with repository collaboration.

### 06. Privacy, security, and administration

- Explain the purpose of two-factor authentication (2FA).
- Describe authentication, permissions, roles, and repository access concepts.
- Recognize foundational practices for protecting GitHub accounts and project data.

### 07. The GitHub community

- Describe the benefits of open-source participation.
- Explain how community contributions can improve shared projects.
- Identify GitHub Sponsors as part of the broader GitHub community ecosystem.

## Suggested repository activities

Each module can be reinforced through a small, observable task:

1. Create or explore a repository and document its purpose in a README.
2. Make a change on a branch and record it in a commit.
3. Open an issue and submit a pull request for review.
4. Organize work in a GitHub Project.
5. Describe a simple automation or development-environment scenario using Actions, Copilot, or Codespaces.
6. Review account-security and repository-access settings.
7. Find an open-source project and identify a constructive way to participate.

## Recommended sequence

```text
Foundations -> Repositories -> Collaboration -> Modern development
	-> Project management -> Security and administration -> Community
```

Learners should complete the modules in order, but each module is also designed to stand on its own as a reference.
